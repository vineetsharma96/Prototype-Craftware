# 🌐 Business Website — Project 1

A responsive frontend business website built as my first complete web development project. The project focuses on creating a clean user interface, presenting business information effectively, and providing direct communication through WhatsApp.

«My first step into building real-world web projects.»

---

✨ Features

- 📱 Responsive frontend design
- 💬 Direct WhatsApp messaging
- 🖥️ Business-focused landing pages
- 🎨 Clean and user-friendly interface
- 📑 Structured sections for presenting information
- 🤖 Experimental AI Chat Assistant integration
- ⚡ Fast and lightweight frontend

---

🤖 AI Chat Assistant

An AI-powered chat assistant was attempted as part of this project.

The integration was an experimental implementation and was not fully functional in the final version.

This experience helped identify the challenges involved in connecting frontend applications with AI services and motivated me to explore proper backend/API integration in later projects.

---

💬 WhatsApp Integration

Users can directly contact the business through WhatsApp without requiring a separate contact form or messaging system.

This provides a simple communication flow:

Website → WhatsApp → Business
